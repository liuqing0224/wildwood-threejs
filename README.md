# 林间筑梦 · Wildwood

一个可直接游玩的浏览器 3D 建造与防守游戏。

## 启动

```sh
npm install
npm run dev -- --host 0.0.0.0
```

## 操作

- 点击底部建筑或家具后进入一次待放置状态，预览才会跟随鼠标；点击营地完成放置后预览自动结束，需要再次点击目录物品才能继续放置。绿色预览代表可放置，红色代表占用或限制。
- 没有待放置物品时，直接点击场景中已经建好的建筑或家具会将它右转 90°；点击空地不执行操作。需要左转时进入已建部件旋转模式后使用 Shift+点击。
- 点击阿木旁边的脚印切换散步模式，再点击营地目的地。点击阿木头像可拉近视角并打招呼。
- 鼠标左键拖动平移，右键拖动旋转，滚轮缩放。触屏单指拖动平移、双指缩放旋转。
- 数字 1–6 选择部件，R 旋转，G 显示网格，空格暂停或继续。
- 建造时使用左右旋转按钮，每次点击固定旋转 90°，在 0°、90°、180°、270° 四个方向循环。点击中间角度可右转，角度控件上滚动鼠标滚轮可双向切换；场景中按住 Shift 滚轮也可旋转，普通滚轮仍用于缩放。R 每次右转 90°，兼容中文输入法的物理 R 键。切换部件不重置方向，旧存档中的自由角度会自动吸附到最近方向。
- 已建部件：按 Q 或点击「旋转已建部件」按钮进入旋转模式，再点击场景部件右转 90°并选中；Shift 点击左转，或用左右按钮、角度控件滚轮继续逐次调整。按 B 或选择部件返回建造。旋转不扣材料、不改变耐久，方向随存档恢复。
- 木墙和栅栏的正反方向均可调整；栅栏正反外观接近，可结合角度确认。右键拖动可绕建筑旋转视角。旋转改变实体方向，不改变当前版本的网格占位、寻路和屋顶支撑格。
- WASD 或方向键按当前视角移动阿木，镜头随行；松开停止，切出窗口清除按键。开始手动移动会停止自动托管。
- B 建造、V 采集、C 维修、M 散步；E 在身边操作（建造为面前一格），F 攻击附近怪物。键盘劳动会在走近并完成动作后结算；原有鼠标点击操作保持即时结算。
- T 开关自动托管；阿木面板可选择「发展家园」「持续采集」「维修巡查」，也有触屏操作按钮。
- H 回屋避险并留守；重新移动或点击地面可接管，T 可恢复托管。
- 斧头模式下点击树木或岩石采集：每棵树获得 24 木材和 6 纤维，每块岩石获得 18 石料。修理模式下点击受损部件；建筑拆除返还一半材料，完好家具则收回成品。
- 直接点击怪物造成伤害；守卫塔自动攻击 12 格内的怪物。
- 世界设置可切换天气、调整时刻、召唤怪物或重新开始。

## 系统

- 木地板、木墙、木门、瓦屋顶、木栅栏和守卫塔。
- 六类可制作家具：木床、木桌、木椅、木箱、落地灯和编织地毯；材料、成品库存、已摆放家具及方向均随本地存档保存。
- 新家园从随机的上午时刻开始；每个昼夜随机为 4–6 分钟，时间连续前进。天气在晴天、小雨、雷雨之间随机转换，每段持续 45–120 秒，可在设置中锁定。
- 雷雨保留风雨效果，不做整屏强闪；昼夜与天气光照平滑切换。
- 首次来袭前约 110 秒准备时间；怪物通过 A* 寻路接近建筑并破坏。
- 建筑耐久、受损提示、屋顶随承重墙损毁、核心失守结算及重开。
- 本地自动存档（每 15 秒和离开页面时）；不提供云同步或跨设备存档。
- Three.js 场景、OrbitControls 视角、javascript-astar 寻路。程序化低多边形资产，无远程图片依赖。
- 阿木：立体五官、眨眼、招手、步行、挥锤和挥斧；天气与怪物驱动表情、撑伞、对白及守家反应。
- 阿木采用 A* 四方向避障，位置随存档保留；兼容没有角色信息的旧版存档。
- 怪物有不同的步速和围巾、迈步摆臂、拆房挥击及受击摇晃。

## 家具制作

1. 采集树木与岩石，或让阿木执行「持续采集」；采树同时获得纤维。
2. 在底部切换「家具」，选择家具。配方显示持有量与所需量，材料不足时显示缺口并禁用制作。
3. 点击「制作」扣除配方材料，得到一件成品。点击木地板摆放，或用 E 在面前一格放置；摆放只消耗成品，不重复扣材料。
4. 家具栏自动切到屋顶剖开的室内视角，「查看室内」图标可独立开关。屋顶只是隐藏显示，实际避雨条件和耐久不变。手机装修时收起部分角色详情，保留天气、暂停和来袭警告。
5. 家具沿用 R、Q 和每次 90° 的左右旋转按钮。拆除模式点击完好家具会收回成品，可再次摆放；损坏家具须先修理。拆地板前须先收起上面的家具。

| 家具 | 木材 | 石料 | 纤维 |
| --- | ---: | ---: | ---: |
| 木床 | 24 | 0 | 12 |
| 木桌 | 16 | 2 | 0 |
| 木椅 | 8 | 0 | 2 |
| 木箱 | 18 | 4 | 0 |
| 落地灯 | 6 | 6 | 4 |
| 编织地毯 | 0 | 0 | 10 |

- 家具需木地板，同格最多一件立体家具；地毯可叠放在家具下。人物不能走穿立体家具，门内唯一入口格禁止摆放立体家具。
- 阿木在室内且没有行走或劳动任务时，附近木床每秒额外恢复 2 点舒适度，木椅额外恢复 1 点，取最高效果，不叠加。落地灯具有暖色自发光灯罩；木箱目前是陈设，不提供独立储物界面。
- 数字 1–6 仍选择原有六类建筑；成品每种最多 999 件。家具制作由玩家选择，自动代理负责收集原料，不会擅自装修。

## 托管与避险

- 自动任务使用本地规则和 A*，不需要联网或 API Key；真实行走、劳动、扣材料和结算。
- 发展家园会先处理可修复的损伤、采集至少 3 次，再在预定位置建两座守卫塔和一处栅栏。完成后巡查待命；位置被占用或没有通路会提示等待。
- 持续采集会优先维修损伤，再收集可到达的树木和岩石；资源有限，不会凭空刷新。维修巡查修复仍存在的受损部件及核心，不自动重建已拆毁的结构。
- 托管遇小雨回屋避雨；雷雨或怪物来袭回屋守卫；20:00–06:00 在屋内休息。条件解除后重新安排未完成任务，中断不会提前扣材料。
- 屋内需要闭合的墙和门、脚下位置上方有屋顶，并有可走通的入口。门经过时开启、离开门边后关闭；进入后附近屋顶隐藏以便查看人物，不拦截点击，但仍可被破坏。雨滴在屋顶上方停止，不穿进室内。
- 户外小雨与雷雨会降低舒适度，雷雨影响更强，低舒适度减慢行走和劳动。晴天缓慢恢复，室内快速恢复，不增加角色死亡系统。
- 屋内守卫每 1.2 秒攻击 4 格内一只怪物，造成 22 伤害；附近 3 格内的建筑承受怪物攻击减半。其他建筑仍会受损，房屋不是无敌的。
- 墙体破口、屋顶缺失或通路被堵会使庇护失效或无法进入，面板显示具体状态。没有安全屋时需手动修复结构。
- 托管设置、舒适度、当前天气剩余时间与昼夜长度随存档保留；读档重新规划任务，兼容旧版存档。后台和暂停时不推进世界。

## 验证

```sh
npm test
npx tsc --noEmit
npm run build
node scripts/check-game.mjs
node scripts/check-character.mjs
node scripts/check-flicker.mjs
node scripts/check-survival.mjs
node scripts/check-rotation.mjs
node scripts/check-furniture.mjs
```

浏览器检查需要正在运行的开发服务器，并生成桌面、手机、夜间雷雨截图和像素检查结果到 `artifacts/`。使用独立测试存档，不重置当前浏览器的家园。详细交付记录见 `PROJECT_STATUS.md`。

构建为静态页面，发布目录为 `dist/client`。线上存档和本地预览存档属于不同浏览器来源，不共享。
